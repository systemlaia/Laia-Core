# LAIA Agent Permissions

## Safe
- Read files
- List directories
- Search manifests
- Summarize markdown/json
- Create notes
- Create retrieval packets

## Approval Required
- Copy files
- Move files
- Rename files
- Run ingest commands
- Modify Obsidian project notes

## Forbidden For Now
- Delete files
- Overwrite NAS files
- Reorganize NAS folders
- Run destructive shell commands
- Change Docker/system config without approval

## Doctrine
- Index before modify
- Report before execute
- Originals are sacred
- No aggregate archive claim without artifact reference
