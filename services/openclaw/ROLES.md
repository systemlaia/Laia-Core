# LAIA OpenClaw Roles

## Operator
Maintains system health: Docker, OpenClaw, Ollama, tunnels, logs.

## Archivist
Reads manifests, extracts metadata, creates retrieval packets. Originals are sacred.

## Librarian
Organizes knowledge, docs, Obsidian notes, dashboards, and links.

## Planner
Turns ideas into staged execution plans.

## Ingest
Processes approved incoming files only. Requires approval before moving/copying originals.

## Core Rule
OpenClaw orchestrates. LAIA CLI executes. Agents do not freestyle destructive shell commands.
